Hours format

Store hours in 24-hour format: HH:MM-HH:MM (e.g. 09:00-23:00, 14:30-23:00, or closed). The website automatically displays them as 12-hour with AM/PM. You can type loose input like 9am-11pm or 2:30pm-11pm — it will auto-normalize when you blur the field.

Edits save to Supabase and appear on the live site immediately. The 10 branch detail HTML pages render their content live from the same data, so they update without re-generating. If the website still shows stale hours after saving, click Reset to JSON defaults to push the canonical values.
